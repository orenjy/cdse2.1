# 📋 프롬프트 관리 콘솔 프로그램 (Prompt Manager)

Python 기반의 대화형 콘솔 프롬프트 관리 프로그램입니다. 자주 사용하는 AI 프롬프트를 카테고리별로 체계적으로 관리하고 검색, 상세 확인, 즐겨찾기 기능을 통해 효율적으로 사용할 수 있습니다.

---

## 📌 주요 특징 및 데이터 구조

- **인메모리 데이터 구조**: Python의 list 내 dict 형태로 프롬프트 데이터를 관리합니다. (프로그램 종료 시 초기화)
  - 	itle (str): 프롬프트 제목
  - content (str): 프롬프트 내용
  - category (str): 카테고리 (개발, 업무, 학습, 기획 등)
  - avorite (bool): 즐겨찾기 등록 여부 (True / False)
- **기본 프롬프트 내장**: 실행 시 유용한 기본 프롬프트 4종이 사전 등록되어 있습니다.
- **예외 및 입력값 검증**: 빈 입력값 검증, 메뉴 번호 유효성 검증, 인덱스 범위 검사 및 Windows 인코딩(UTF-8) 호환성 처리가 적용되어 있습니다.

---

## 🛠 분리된 핵심 함수 목록 (총 9개)

| 함수명 | 설명 |
| :--- | :--- |
| show_menu() | 콘솔 메뉴 UI 출력 |
| show_list() | 전체 프롬프트 목록 출력 (번호, 즐겨찾기 ⭐, 카테고리, 제목) |
| show_by_category() | 카테고리별 프롬프트 필터링 조회 |
| search_prompt() | 제목/내용/카테고리 키워드 기반 검색 |
| show_detail() | 특정 번호의 프롬프트 상세 내용 및 메타데이터 조회 |
| dd_prompt() | 새로운 프롬프트 추가 (빈 값 검증 포함) |
| 	oggle_favorite() | 프롬프트 즐겨찾기 상태 변경 (⭐ 토글) |
| show_favorites() | 즐겨찾기에 등록된 프롬프트 목록만 모아보기 |
| main() | while 무한 루프 기반 사용자 입력 처리 및 메뉴 반복 제어 |
